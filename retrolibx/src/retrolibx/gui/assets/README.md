# Platform art

These 14 WebP display copies were extracted, without altering the image data,
from the previously approved `docs/design/fluent-workspace.html` prototype.
The prototype uses the existing Canvas_天马G theme's square capsule artwork.

The desktop preview uses these local files so it does not need to read a device
or locate an installed theme. This directory is design-preview material, not a
claim that the original theme artwork is covered by RetroLibX's MIT license.
Confirm the theme/artwork distribution terms before shipping an independent app.
