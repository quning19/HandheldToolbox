软件显示名为“掌机工具箱”；源码启动入口为根目录“掌机工具箱.cmd”。Python GUI 入口同名，安装后 Windows 入口名为“掌机工具箱.exe”，它仍需要已安装的 Python 运行环境及项目依赖。独立发布 EXE 也采用该名称，但尚未执行独立打包；原有模块名、包名、项目目录及旧启动入口保留。

此轮只进行素材保存、ICO 格式导出和静态代码 review，没有启动窗口、运行测试、安装或打包。此前通过的业务/离屏测试记录不覆盖此次名称与图标改动。
