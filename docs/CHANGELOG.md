### 结构与业务

- `src/` 下 retrolibx、library_converter、theme_converter、frontend_gui、平台、设备及公共包平级。两个 converter 互不依赖，也不依赖 Qt；GUI 汇总调用，均保留独立 Python 入口。
- FrontendThemeConverter 的源码、旧工具、测试、原版主题、参考、历史输出和实验资料迁入对应目录；旧工程完整归档。本项目运行时不再调用相邻工程。
- 通用主题解析按 XML/include/变量/条件分支构建资源图，按素材用途生成或继承；七套旧逐主题规则仅作开发对照。主题列表由实际导入/设备同步内容产生，初次可为空，原版和输出分别保留。
- 平台卡片保留四套共 832 张素材，支持 Canvas、Aura、Alekfull NX、iiSU Interpreted 切换及持久化；缺图按本风格母体图、占位回退。
- 默认平台和用户覆盖、新增、禁用分开保存；升级保留用户修改，冲突提示，旧配置迁移前备份。
- 主题结果按原版、输出相关平台依赖、解析器与素材策略版本判定过期，保留旧输出，过期禁止上传。
- 设置提供临时文件、备份与恢复资料、历史日志三类手动清理；业务与清理共用工作锁，未知资料和正式数据保留。样本与旧恢复作业已分类迁移。
- Pegasus 相对 ROM 路径以 metadata 目录为准；缺失引用不使用其他目录同名文件替代。旧绝对路径迁移能力保留，原始 ROM 和 metadata 不改写。
- 名称统一为“掌机工具箱”；保留竖版 1、横版 1、翻盖 1 和橙色手柄原稿，选竖版 1 为多尺寸 ICO。新增“掌机工具箱.cmd”及同名 Python GUI 安装入口；独立 EXE 尚未打包。
