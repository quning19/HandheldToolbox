# 工作目录与清理

基础设置仅保存在程序同级 settings.json，包含工作目录、亮暗外观和卡片风格。其余运行数据在工作目录；不使用 Windows 用户数据目录保存本软件状态。

| 目录 | 内容 | 更新与清理 |
|---|---|---|
| config | 用户平台覆盖、主题结果和解析缓存、工作锁 | 动态；不随清理删除 |
| themes/original | 导入或设备同步的原版 | 动态；保留，更新前备份 |
| themes/exported | 当前完整适配结果 | 动态；保留，过期也不自动删除 |
| library | 本地游戏库正式输出 | 动态；保留 |
| devices | 设备资料 | 动态；本次清理默认保留 |
| backups/library | 扫描快照、平台配置、转换计划、发布回执及共用素材核对记录 | 恢复资料，按关联批次保留 |
| backups/themes | 被替换的原版或输出及恢复位置说明 | 恢复资料，手动选择后可清理 |
| backups/config、migrations | 配置升级前文件、目录迁移映射与引用旧副本 | 恢复资料 |
| temp | 带程序临时标记的主题暂存、索引、中间图和未发布副本 | 可重建；失败或中断不单独分类 |
| logs | 当前 desktop.log 和历史日志 | 当前日志保留，历史日志可手动清理 |

设置只有一个“清理工作目录…”入口，三个分类：临时文件（默认勾选）、备份与恢复资料、历史日志。预览提供批次数、文件数、空间、文件明细；最新备份批次默认不勾选，可由用户明确逐项选择。用户确认后才永久删除所选项。预览后的文件有变化则要求刷新，不继续执行旧清单。

清理和业务共用工作目录锁，运行任务期间不能清理；程序退出或崩溃后由操作系统释放锁。链接、junction、越界路径不删除。用途未登记的旧 temp、人工样本、设置、平台定义、当前主题、正式游戏库、ROM、游戏素材始终排除。清理不连接设备，也不删除远端文件。

清理恢复批次后 GUI 会清空此前加载的平台列表，避免继续使用已经被清理的快照。已存在于正式输出附近的 .frontendtrans.bak 以及历史 jobs 中的资料不自动搬移或删除；首版保持保守边界，不增加按天清理或失败任务管理页面。
