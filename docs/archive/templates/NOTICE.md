# Android GBA模板来源

android-gba-3.4.1.xml仅节选官方ES-DE v3.4.1 Android系统表的GBA节点：

- [官方源文件](https://gitlab.com/es-de/emulationstation-de/-/raw/v3.4.1/resources/systems/android/es_systems.xml)
- [官方MIT许可证](https://gitlab.com/es-de/emulationstation-de/-/raw/v3.4.1/LICENSE)，完整版权及许可保存在[ES-DE-LICENSE](ES-DE-LICENSE)。

模板仅为历史启动格式参考，不作为当前默认配置，也不证明本机模拟器或核心可用。当前使用[examples/profile.local.json](../../../examples/profile.local.json)及共用完整平台XML；单独clone时需调整实际输入/设备目录。
