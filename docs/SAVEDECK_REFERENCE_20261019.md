# SaveDeck 官方成品对比（2026-10-19）

后续规则变更：用户决定 ES-DE／SaveDeck 共用从 PegasusGGameManager 适配的媒体补找，对失效或未填引用按目录优先级查找，同级多个候选选第一个并报告。当前媒体选择不再完全沿用官方编辑器；下述成品一致性及旧媒体选择规则均为历史记录。本页仅保存历史成品对比，后续最小定向检查与设备验收见 [SaveDeck 说明](SAVEDECK.md) 和 [设备记录](TESTS_FRONTEND_DEVICE_20261019.md)，当前规则见 [来源说明](engine/SOURCE_PROFILES.md#媒体)。

## 后续筛选与命名规则变更

用户在模拟器中的 SaveDeck 前端观察到，TOML 中登记的游戏即使没有 ROM 也会显示，因此要求按入口文件是否存在筛选最终 TOML。当前实现已排除缺失入口及其新媒体任务，合并已有配置时也移除缺失 ROM 的旧条目；游戏独立 launch 保留；后续统一同步规则进一步要求移除未登记条目，两种模式均不删除旧媒体或修改天马配置。后续经用户授权，34 项 SaveDeck 定向用例已取得通过结果，见 [测试记录](SAVEDECK.md#定向测试2026-10-19)；没有重跑本页历史成品对比或全量测试。模拟器样本的生成、清理与上传按用户另行授权执行。

用户随后确认普通多 ROM 版本的名称按实际存在入口数量生成：一个存在时使用原游戏名，多个存在时分别使用 ROM 文件名去扩展名；已有 TOML 名称在“全量覆盖”时刷新，媒体目录也采用对应名称。后续只读查看的官方 PS1 TOML 将最终幻想8拆为四条 CHD 入口，而保存的前端数据库只有一条并指向 Disc 1；用户要求将该多盘差异暂缓，见 [SD-001 待处理事项](PLAN.md#savedeck-待处理事项)。运行时换盘方式尚未确认，不据此改变普通多版本策略。

以下 652 个入口、1269 个媒体及逐字节一致结果属于筛选与命名规则变更前的历史证据，不表示当前版本在含缺失 ROM 或多 file 时仍生成相同文件集合。

**ID 对比方式**：与官方一样，独立首次导入生成 UUID v4，本次生成的 652 个 ID 均合法且各平台内唯一。两次独立导入的随机 ID 不同是预期差异。复用 ID 的检查只将官方已有 `file`、`id` 和占位 name/platform 提供给实际 `merge_documents(..., replace=True)`；没有用官方简介、媒体路径、sort 或扩展字段填补生成结果。除 ID 外，首次生成结果已经没有字段差异；合并后完整 TOML 字节也完全一致。

**缺失资源处理**：GBA hack 的 9 个缺失 ROM 引用现在按官方“不复制 ROM”分支保留并报告，不再阻止整个平台导出。未改写引用、补造 ROM 或筛除条目。显式媒体引用失效时省略对应字段；不再使用另一文件猜测替换，因此先前多出的 26 个封面、9 个视频字段也已与官方对齐。

**复制选项的范围补充**：用户随后指出官方勾选与不勾选“复制 ROM 文件”时，缺失 ROM 是否生成条目存在差异。继续静态阅读同一 EXE 的导入分支可见：`0x140033F60` 一带根据选项决定是否调用 ROM／依赖解析（`0x14004E010`）；缺失异常在 `0x14003B2C9` 一带转为跳过并记录“缺 ROM 或依赖，已跳过”。不复制时可以只登记路径。本工具共用原 ROM，当前保留缺失入口对应不复制分支；上面的三平台成品一致结论不能推广为官方所有选项组合均一致。本次补充仅做静态 review，未启动官方程序、重跑成品对比或执行测试。

**官方实现依据**：对用户提供的原生编辑器 1.0.1 EXE 做静态 PE／反汇编检查，未启动程序。EXE SHA-256 为 `ce88df5b99a35119b9798811453e50f0c7fab2bc8a411d6cb9805997f45dd3a4`。别名表在 `0x1400082DF` 一带，显式素材选择在 `0x14000A376` 一带，默认封面名称优先级在 `0x14000AB0E` 一带，原字段扩展命名在 `0x14000E900` 一带。反汇编及相关字符串注释仅留在本地 artifacts，没有将官方程序内容作为产品依赖。

**原件和检查边界**：六份输入配置前后 SHA-256 一致，来源目录中的 SaveDeck 配置存在状态不变；所有生成写入都在 artifacts。没有运行单元／集成／GUI 用例、lint、类型检查、构建或实际设备操作。此次证据覆盖所提供三平台的媒体和 TOML 生成，不代替设备发布、实际启动或其他数据边界的验收。

### 与共用原目录方案有关的差异

- **UUID**：官方 652 个 ID 为 UUID v4，当前为 UUID v5。两次独立导入的 ID 字面值不同属预期；应检查合法、唯一及后续更新时稳定，不强求重建官方随机 ID。本轮未重跑 ID 稳定性用例。
- **媒体路径**：官方复制并改名为 `cover.png` 等文件，当前直接引用来源 `boxfront.png`／`boxFront.png` 及原视频目录，符合已确认的共用方案。共同引用的 **1269 对媒体内容全部相同**，没有不可读文件或内容差异；按唯一文件缓存共读取 2459 个媒体文件，未读取 ROM 内容。
- **额外媒体字段**：当前在官方未写字段的入口中，仍能找到 **26 个封面、9 个视频**并提供有效原路径。这些字段差异未被当成内容不一致，也未为了仿照官方而删除来源资源或省略现有有效媒体。

### 来源问题：GBA hack

正常解析发现“仙剑奇侠传”第 4–9 卷的合计 9 个文件引用不存在，具体引用见本地 `analysis.json`。官方配置仍登记这些入口，当前正式用例按现有规则阻止该平台发布。

本轮保留该失败状态，没有全库资源盘点、猜测替换文件、改写 metadata、跳过入口或放宽发布规则。是否修复来源资料，或改为允许携带缺失引用导出，属于后续独立决策。
