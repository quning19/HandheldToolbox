# Windows 页面与业务约定

更新日期：2026-10-19。软件名 **掌机工具箱**，PySide6、Qt Widgets 与 QFluentWidgets 的 Fluent 工作台。本文保存当前已确认行为；原始五组实施清单和旧原型说明已 [归档](archive/plans/2026-10-16-windows-approved-scope.md)。当前实现、手测反馈与测试边界见 [状态](engine/STATUS.md)，后续事项只在 [计划](PLAN.md) 维护。

## 页面与公共区域

两个主业务页面是游戏库转换、主题管理。设置位于侧栏底部，平台管理作为设置子页面，不增加任务、对比或历史主页面。窗口可调尺寸，切页不改变窗口大小；顶部放操作及当前参数，列表占主要区域。游戏库保留固定反馈面板，主题使用固定 32px 状态行，任务开始与结束不挤动内容。

底部状态栏显示当前设备、连接方式和存储识别信息，不显示工作目录。程序同级 settings.json 保存唯一工作目录、亮暗模式和平台卡片风格；其他数据自动进入工作目录子目录。应用、窗口及侧栏选用竖版掌机 1 图标。

## 游戏库转换

来源为电脑目录或掌机。切换来源/路径只更新选择并清空旧结果，点击“加载平台”才检测。掌机区分内置存储与 SD 卡，查找 rom/roms 类目录，候选阶段仅显示直接子目录数量，不递归识别游戏。点击刷新可连接已运行的模拟器，不自动启动模拟器。

平台在后台逐个检测，每完成一个就在矩形网格追加。来源变化取消旧检测，防止结果混入。卡片上部铺满平台图、名称居中描边，下部显示 ROM 与封面覆盖数；四套风格可在设置切换，专用图缺失时用同风格母体图，再用占位。

| 情况 | 计数与转换 |
|---|---|
| metadata 多个版本且对应 ROM 存在 | 各版本分别计数和导出；同一源封面按各 ROM 输出对应副本 |
| 多轨光盘 | 按描述文件入口计数，其引用轨道不作为额外游戏 |
| metadata 引用缺失 | 提示缺失，不计入实际数量，不改源 metadata，不借其他目录同名文件顶替相对路径 |
| ROM 未被 metadata 收录 | 提示未关联，不猜测游戏资料 |
| 封面统计 | 仅判断游戏封面，不逐项检查三类媒体；平台卡片图与封面统计分开 |

顶部包含来源、目录、加载按钮，以及自动目标、共用素材、全量替换、开始转换。掌机默认使用内置 ES-DE 目录，电脑输出自动进入工作目录。目标存在歧义才要求选择。

默认依据已有 gamelist 的平台及 ROM 相对路径跳过已有入口，仅处理新增，不判断旧媒体内容变化。“全量替换”处理所选平台当前识别到的全部入口及媒体，不清空目标或删除旧额外条目。共用素材默认关闭，开启后的核对和来源更新约束见 [共用素材](engine/SHARED_MEDIA.md)。

新设备初始化完整四文件系统配置；已有配置保留用户节点及启动参数、补齐所需定义和伴随文件，无需手工维护。游戏/媒体只处理所选范围。已有列表字段保护、文件夹封面和启动规则见 [业务说明](engine/PROJECT_GUIDE.md)。

## 主题管理

官方主题目录、原版与适配结果由工作目录管理，支持在线下载／更新、本地导入、转换、设备刷新与上传；来源和备份规则见 [主题说明](THEME_CONVERSION.md)。

- 顶部为刷新目录、检查更新、刷新设备；本地导入放页面“更多”。批量栏只操作勾选项，未勾选时禁用；下载并转换和删除放批量“更多”。
- 列表为缩略图、名称、原版／适配／设备状态。名称列最多 240 逻辑像素，纵向滚动条独立占 20 像素；点击行或状态只切换预览，作者只放详情。
- 完成、更新、需重转和失败采用 28×28 带框图标；没有或未知的 `×`、`—` 保留 18px 无框符号。悬停显示完整说明。
- 名称搜索与三类状态筛选可组合，全选仅当前可见行，筛选变化清空勾选；筛选复用原行和解码缓存。
- 右侧提供大图、可点击缩略图、箭头、页码和简短资料。四图可同时显示，更多图片横向滚动；缩略图框宽高联动、最大约 150×84，原图按自身比例完整显示。长资料单独展开。
- 底部 32px 状态行显示任务阶段。下载和目录刷新显示真实阶段百分比及 Git 提供的容量／速率，主题批次另显示序号与名称；无百分比时用动态等待条，静默时更新等待秒数。
- 任务期间列表可滚动及切换预览，勾选、筛选与冲突操作锁定。取消结束本次后台进程；正式替换阶段暂不可取消。主题上传要求有效适配结果，设备“已有”仅表示存在。

## 设置与平台管理

平台定义供两个业务共用，支持搜索、手动添加、编辑和删除。配置包含名称、ROM 目录、母体、沿用/独立主题表现及角标；内部 ID 稳定，不因改显示名而变化。删除不连带删除 ROM、设备配置或输出，母体引用需提示。

新版默认平台和用户覆盖、新增、禁用按字段合并；旧配置迁移前备份，冲突保留用户项并提示。详见 [平台配置](engine/PLATFORMS.md)。

设置只有一个清理入口，分临时文件、备份与恢复资料、历史日志；默认仅选临时文件，最新备份默认不选。预览明细再删除，有变化要求刷新；运行任务、正式数据和未知资料受保护。不增加失败/中断任务单独页面，详见 [工作目录](WORKSPACE_DATA.md)。
