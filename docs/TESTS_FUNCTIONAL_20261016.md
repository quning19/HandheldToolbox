## 路径修复与定向测试

Pegasus 导入 ROM 时启用严格相对路径解析：以 metadata 所在目录为准，不向库根目录、其他子目录或同名文件回退。没有找到的引用仍保留原路径并作为缺失处理，不筛除或改写原始 metadata。旧设备 POSIX/Windows 绝对路径继续保留迁移匹配；媒体解析及其他适配器不启用这项严格模式。

定向测试共 17 项全部通过：13 项新增路径回归（不同目录/层级、正反斜杠、带 ./、裸文件名、全库与所选平台模式，以及三种旧绝对路径），3 项既有相关用例，1 项真实 GBA 连续流程。没有继续扩大测试范围。

真实 GBA 流程验证扫描数量为 8/8/4，首次转换 20 个并生成完整四文件平台配置；第二次转换 0 个，已有媒体大小及修改时间不变；在新的隔离副本中加入预留的两个真实 ROM 后仅转换 2 个，最终三个 gamelist 共 22 个游戏入口。原始样本索引保持不变。
