# 项目工作约定

## 当前范围

基于RetroLibX扩展天马G/Pegasus到Android ES-DE。保留多前端能力，按当前方向逐步交付。当前状态看[状态](../docs/engine/STATUS.md)，使用说明看[README](../README.md)，历史设计在[docs/archive](../docs/archive/README.md)。

Python运行要求3.12+；frontend_platforms保持标准库及Python 3.9兼容。依赖集中维护于pyproject.toml和uv.lock，不把缓存或候选源码作为产品依赖。

## 实现边界

```text
来源适配器 → Library通用模型 → 目标ExportIntent → ConversionPlan → PlanExecutor
```

- 不新增格式之间的点对点转换器。Adapter只解析或渲染，不直接写目标、复制媒体或执行来源launch。
- Planner处理路径及冲突，Executor执行文件操作；dry-run不产生目标文件。
- 可变模型字段使用default_factory；原始来源字段保存在命名空间metadata中。
- 平台目录、别名和Hack识别使用共享配置，不重新硬编码在Adapter。
- 平台XML以主题工具已验证的完整四文件为维护基线，JSON仅保存别名、母体、类型和角标。发布副本不作为第二套手工定义。
- 天马包约定使用来源profile。普通Pegasus默认generic，Android任务默认pegasus-g。
- 普通ES-DE convert和Android build共用列表合并，保留旧非空字段、补空及追加，并带基线保护和备份。
- 当前不调整排序策略，不增加符号链接导出方案；上游保留能力不构成当前补齐任务表。

## 数据和设备

- 默认保持来源ROM、metadata和媒体只读，不顺带操作真实资源。用户已确认可选共用素材模式：默认关闭；明确开启时，只更新原metadata的封面、Logo、视频引用，所有目标素材核对成功且metadata发布后再清理对应源素材。ROM、mini及其他内容不变，仍被其他字段引用的源素材保留并报告。
- 计划和执行均限制目标路径；XML禁止DTD和外部实体加载。
- 递归发现元数据，路径歧义报告错误，不猜测平台、核心或文件目录。
- Android只处理所选游戏/媒体，平台配置始终完整；配置变化停止执行。
- 多平台通过一次build生成单个任务，不逐平台拼接脚本或平台XML。电脑端deploy复用upload/publish，支持单步授权并统一记录耗时；不在jobs编写新的部署工具。平台模板引用和已批准的metadata启动转换使用现有配置项，不为固定设备另造生成脚本。
- 设备脚本采用最小设计，只创建目标媒体目录并拷贝明确选中的文件；不包含哈希、大小、临时文件、恢复状态或发布业务。gamelist、平台配置及原 metadata 的备份、发布和源媒体清理由电脑端通过普通 ADB 命令执行，不混入设备脚本。普通复制不重复检查 ROM 和全部素材；只有共用迁移在修改原 metadata、删除源素材前核对副本内容。预览、计划、发布清单和 XML payload 留在本地，设备仅上传所需媒体脚本。
- 掌机写入需要用户授权，视觉、实际启动和震动由用户验收。
- 设备、卡号和目录从当次确认或配置取得，历史报告路径不作为当前配置。

## 检查与测试

执行任务与资源异常检查分开授权。用户要求生成 gamelist、拷贝媒体时，只按已确定规则处理所选范围；读取生成所需 metadata、解析路径及接收执行命令的成功/失败属于正常执行，不据此扩展异常盘点。

- 未明确要求时，不主动开展 metadata 与实际 ROM 的全库匹配、缺失/孤立/重复资源盘点、完整性核对或旧数据兼容排查；拟做这些检查时，先列出独立检查任务、范围和必要性，获用户批准后再执行。只读不代表这些专项检查自动获得授权。
- 正常解析或拷贝中自然发现异常，记录具体问题及对本次执行的影响即可；将异常检查和修复拆为独立任务。不得顺带筛除记录、改写 metadata 捕获副本、补兼容规则、改变启动配置、修复或重新生成整批任务。
- 受异常阻塞的项保留失败状态，不静默修正或跳过后宣称完成；其他已获授权且不依赖该问题的项可继续。批准清单不覆盖后续新增检查或修复。
- 生成、拷贝、发布、检查、修复、测试在任务清单和时间记录中分别标明；已有发布基线保护等程序内置约束照常生效，不能把它们扩展为人工专项排查。新增检查业务不能默认混入执行流程。

默认阅读源码及diff做静态review。测试、覆盖率、lint、类型检查和构建依用户明确批准的范围执行；实施授权不代表这些命令已获批准。小改动不自动触发全量测试，不扩大或重复批准范围。

测试覆盖模型/注册表、适配器、计划/执行器、服务/CLI、Android任务、平台及来源规则。修改逻辑时补充有意义的用例；未获准执行时记录未执行，不能声称通过。

独立命令入口为 `python -m library_converter`、`python -m theme_converter`、`python -m frontend_gui`；原 `python -m retrolibx.cli` 保留。GUI 不拥有业务模型，两个 converter 互不导入、不依赖 Qt。文档中的安装、测试、构建和发布命令不构成执行授权。发布及线上写入另按用户要求处理，保留上游来源和许可证。

## 文档与清理

当前结论集中到STATUS及对应功能说明；长过程、旧设计和模板归档。变更配置及保留行为时同步文档，不维护互相矛盾的当前说明。

清理确认可重新生成的缓存和临时文件，保留运行环境、真实样本、设备快照、用户查看过的导出及证据。Windows递归删除/移动前确认绝对目标在工作区内，使用PowerShell的LiteralPath，不跨shell拼接删除命令。清理不自动运行测试或重建环境。
