# Platform art

cards/index.json lists all 832 platform display copies from four real themes:
Canvas 229, Aura 218, Alekfull NX 182, iiSU Interpreted 203.
The WebP images occupy 40,732,940 bytes; source images are resized to fit 640×480
without distorting the aspect ratio. Each entry records its original source.

Original license files, where provided, and the original READMEs are retained
alongside each style. The application's source MIT license does not relicense
these third-party graphics. Distribution conditions must be handled before an
independent release. No complete source themes are included in the application.

The previous 14 prototype images remain in docs/design/assets/legacy-platforms.
Some custom Canvas platform images use those approved preview sources. Missing
images resolve only to the mother platform in the selected style, then a generic
placeholder. They never silently switch to another style.
